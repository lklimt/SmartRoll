# SmartRoll – Project Overview

## Purpose

SmartRoll is an automated roller-blind control system combining mechanical drive components, rotational sensing, electronics, firmware and Home Assistant integration.

## Documentation principle

The repository is the long-term technical record of the project. The current approved `SPECIFICATION.md` is the source of truth for parameters.

## Development principle

Design iterations must preserve confirmed parameters unless an explicit change is agreed and recorded in `CHANGELOG.md`.

Unknown values remain `OPEN` until confirmed.
