# Hall Sensor Test Evidence

Store original test evidence here:

- photographs,
- serial monitor captures,
- oscilloscope screenshots,
- measurement notes,
- test videos.

Do not overwrite original evidence. Use descriptive filenames with a test stage prefix, for example:

`T1_01_single_magnet_switching.jpg`
`T3_02_AB_sequence.txt`
`T4_01_two_magnets_video.mp4`
